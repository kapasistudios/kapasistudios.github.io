Exclusão de dados

KAPASI STUDIOS · Mar dos Piratas (com.maressemlei.jogo)

Mar dos Piratas não mantém servidores: o progresso do jogo existe apenas no seu aparelho. Por isso, a exclusão dos dados é feita por você, na hora, pelos caminhos abaixo.

1. Apagar o progresso do jogo

  • Dentro do jogo: Configurações → Conta → Zona de perigo → Apagar este capitão. Isso remove o progresso e os pontos de restauração daquele espaço, sem como desfazer.
  • Removendo tudo: desinstale o aplicativo ou use Configurações do Android → Apps → Mar dos Piratas → Armazenamento → Limpar dados. Todo o progresso é apagado definitivamente.

2. ID de publicidade (anúncios)

O Google AdMob usa o ID de publicidade do aparelho. Você pode redefinir ou excluir esse ID em Configurações do Android → Google → Anúncios. Para rever o consentimento de anúncios do jogo, use Configurações → Conta → Opções de privacidade.

3. Histórico de compras

As compras são registradas na sua conta Google, não conosco. Você pode consultá-las e gerenciá-las em play.google.com/store/account.

4. Precisa de ajuda?

Escreva para kapasistudios@gmail.com que orientamos o passo a passo. Como não armazenamos dados pessoais, não há nada adicional a excluir do nosso lado.
